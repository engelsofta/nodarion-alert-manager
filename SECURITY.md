# Security Policy

## Supported versions

Security fixes are applied to the latest published release.

## Reporting a vulnerability

Please do not publish vulnerabilities, tokens, Home Assistant diagnostics or private entity data in a public issue. Use GitHub's **Report a vulnerability** function in the repository's Security tab. Include only the minimum information required to reproduce the problem and redact entity IDs, hostnames, IP addresses, notification targets and access tokens.

We will acknowledge a report as soon as possible, investigate it privately and coordinate disclosure after a fix is available.
